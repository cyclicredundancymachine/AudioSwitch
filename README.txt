AUDIOSWITCH
Use the wider volume slider and normal-height Mute/Unmute button beside Bluetooth to control the current
Windows playback output. Mute sits to the left of the slider; no percentage is shown.
The controls refresh when Windows volume changes.

Double-click the tray icon to open AudioSwitch. Under Available outputs, click Use
beside an available device to select it, even if Windows connected it first.
Drag a window edge to resize. Hover over the current output to see its full name.
For a disconnected paired headset, use Connect to connect and select it.
Pair new devices through Windows Settings. Sound opens Windows audio settings.
Bluetooth opens Windows Bluetooth settings.

Use Devices to hide devices or show them again. Windows pairing is unchanged.
The headphones icon is blue when Bluetooth is on, red when off, and gray when unknown.
Hover or single-click to see Bluetooth status and the default playback device.

Close the window to keep AudioSwitch in the tray. Use Exit to quit.

To share, copy this folder to a compatible Windows x64 PC. Keep both EXEs,
this README, and the license together. Open AudioSwitchTray.exe. Device
preferences and sign-in startup are set separately on each PC.

Inspection uses a helper with a 12-second deadline. If Windows stops responding,
AudioSwitch reports the failure and retries on a later refresh. Mute toggles the
current output's live state. Volume refresh waits while you drag the slider.

INSTALLATION AND UPDATES
Windows x64 Setup and a portable ZIP are available at:
https://github.com/cyclicredundancymachine/AudioSwitch/releases/latest
Exit AudioSwitch before installing an update. Setup adds a Start menu shortcut
and an uninstall entry. It preserves device preferences and does not enable
sign-in startup. Choose the existing app folder to upgrade a portable copy.
Uninstall through Windows Installed apps; saved preferences are retained.
