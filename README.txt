AUDIOSWITCH

Double-click the tray icon to open AudioSwitch. Under Playback outputs, click Use
beside an available device to select it, even if Windows connected it first.
For a disconnected paired headset, use Connect to connect and select it.
Pair new devices through Windows Settings. Sound settings opens Windows audio settings.

Use Device list to hide devices or show them again. Windows pairing is unchanged.
The headphones icon is blue when Bluetooth is on, red when off, and gray when unknown.
Hover or single-click to see Bluetooth status and the default playback device.

Close the window to keep AudioSwitch in the tray. Use Exit to quit.

To share, copy this folder to a compatible Windows x64 PC. Keep both EXEs,
this README, and the license together. Open AudioSwitchTray.exe. Device
preferences and sign-in startup are set separately on each PC.
